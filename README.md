# Online-Book-Store-Management-System
Developed a web-based Online Book Store Management System using Java, JSP, JDBC, and Oracle Database. Implemented user authentication, book catalog management, shopping cart, and order processing features. Integrated database operations to provide a secure and seamless online book purchasing experience.



# Online Book Store Management System

## Overview

The Online Book Store Management System is a web-based application developed using Java technologies. It enables users to browse, search, and purchase books online through an interactive and user-friendly interface. The system also provides secure user authentication and efficient order management.

## Features

* User Registration and Login
* Secure Authentication
* Browse and Search Books
* Book Catalog Management
* Shopping Cart Functionality
* Order Processing and Management
* User Profile Management
* Database Integration for Data Storage

## Technologies Used

* Java
* JSP (Java Server Pages)
* JDBC
* Oracle Database
* HTML
* CSS
* JavaScript

## Project Structure

* Frontend: HTML, CSS, JavaScript, JSP
* Backend: Java, JDBC
* Database: Oracle Database

## How to Run

1. Install Java JDK and Apache Tomcat.
2. Configure Oracle Database and create the required tables.
3. Update database connection settings in the project.
4. Deploy the project on Apache Tomcat Server.
5. Start the server and access the application through a web browser.
